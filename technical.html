Under the hood

How it’s made

A native Apple Watch app written in Swift and SwiftUI, with a small iPhone companion.

  • Swift
  • SwiftUI
  • WebKit
  • AVKit
  • StoreKit 2
  • watchOS 10+
  • iOS 17+

At a glance

Apple Watch
watchOS 10.0 or later; runs on its own, without the iPhone nearby
iPhone
iOS 17.0 or later: guide and tips
Web engine
The system’s WebKit, the same engine as Safari
Languages
34, from a single shared String Catalog
Account
Not needed. Bookmarks, history (up to 300 pages), tabs and settings are stored on the watch
Purchases
Three consumable tips with StoreKit 2, on iPhone only
Own server
None. There’s no developer backend, analytics or crash reporting

The foundation

Content blocking

A WKContentRuleList, the same mechanism Safari content blockers use, drops requests to more than 190 ad and tracker domains inside WebKit’s network process. A second list hides cookie banners from the most common consent platforms, and leftover ad slots are hidden with CSS.

Video

A small script reports every playable video on the page. Orbita opens it in AVPlayer, where the Digital Crown has a single owner: you choose whether it controls volume or seeking. The audio session follows route changes to AirPods.

Tabs that sleep

Each tab keeps its address and title. Only recent tabs keep a live page; older ones go to sleep and reload when you come back, so memory stays low on the watch.

Site versions

Orbita asks sites for their iPhone, Mac or watch layout by changing the user agent. The iPhone version is the default because it fits the small screen best.

Project structure

The project is generated with XcodeGen. The watch app and the iPhone app share the theme and the translations.

Orbita/              // Apple Watch app
├── App/             // entry point, settings, theme
├── Browser/         // web view, tabs, menu, blocker, video player
├── Features/        // home, tabs, bookmarks, history, settings, about
├── Store/           // bookmarks and history saved as JSON
└── Resources/       // blocklists, String Catalog, icon
OrbitaPhone/         // iPhone app: guide and tip jar
OrbitaTests/         // unit tests
OrbitaUITests/       // interface tests on the watch simulator

Privacy by design

  • No sign-up: no name, email or phone number.
  • Local data: bookmarks and history are small JSON files on the watch; deleting the app removes them.
  • Blocklist inside the app: applied without contacting any server.
  • No third-party SDKs: no analytics, ads or crash reporting.
  • Apple processes tips; the developer never sees payment details.
